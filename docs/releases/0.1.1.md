# Lampwright 0.1.1 release notes

Lampwright 0.1.1 is a patch release for the first cross-platform release. It
fixes the isolated CLI startup failure that occurred when Gemini CLI's user
home and current workspace were the same directory. Coincident Gemini Skill
roots and settings are now represented once while preserving the documented
workspace precedence and user configuration applicability.

The release preserves Lampwright's existing safety boundaries: Inventory scans
remain bounded and read-only, Git-protected content and System Skills remain
immutable, and Managed Removal, Quarantine, Native Disable, and Disabled
Storage behavior are unchanged. It requires Node.js 20 or newer and supports
macOS, Linux, and Windows.

After the GitHub `v0.1.1` release has been created and verified, npm
publication may be authorized separately. Until then, run from a trusted
checkout with `npx --no-install lampwright`.
