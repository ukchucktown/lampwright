# Lampwright 0.4.0 release notes

Lampwright 0.4.0 adds themes to the terminal interface and replaces its
four-row header. It also corrects a Managed Update that added Skills to more
agent harnesses. Lampwright requires Node.js 20 or newer and supports macOS,
Linux, and Windows.

## Themes

The terminal interface now follows the theme of your terminal. The new default
theme, `terminal`, uses only the 16 palette colors of the terminal, the default
foreground and background, and the bold, dim, and reverse attributes. It reads
correctly on a light or a dark background.

Earlier releases had one theme, `Nightfall`, with fixed colors for a dark
background. `nightfall` is still a built-in theme. If you prefer the earlier
colors, select it in the theme picker.

Press `ctrl+p` in a browse view to open the theme picker. The browse view
behind the picker shows each theme as you move through the list. Enter applies
the theme and saves it. Escape restores the previous theme.

You can also write a theme. A custom theme is a TOML file in the `themes`
directory of the Lampwright configuration directory, which is
`~/.config/lampwright` unless `XDG_CONFIG_HOME` or, on Windows, `APPDATA`
gives a different location:

```toml
name = "ocean"
extends = "terminal"

[styles]
title = "#3399ff bold"
focus = "white on #484e5b bold"
error = "bright-red"
```

Each style has the form `<foreground> [on <background>] [attributes]`. A theme
file that is not valid does not stop Lampwright. The picker lists the file with
the reason.

The `--theme <name>` option and the `LAMPWRIGHT_THEME` environment variable
select a theme for one run and save nothing.

## One new file

When you confirm a theme in the picker, Lampwright writes the `theme` value of
`config.toml` in its configuration directory. This is the first preference
that Lampwright saves. A scan, a browse, a preview in the picker, and a dry run
still create no files.

## Header and key reference

The browse views now use two rows above the panes in place of four. The first
row shows the views and the number of selected rows. The second row shows the
keys for the current view:

```text
space select · enter remove · u update · d disable · / search    ? help · q quit
```

Press `?` to open the key reference. It lists each key with its effect and the
mouse action that has the same effect. The panes gain two rows of space.

These points also changed:

- Each row of a section shows the agents that can load the Skill.
- A key chord uses a plus sign: `ctrl+t`, not `ctrl-t`.
- The scrollbar is a thin mark with no track, and the panes have no right
  border.
- Escape responds in about 50 ms. In earlier releases it took about 500 ms.
- A selected or cleared section no longer shows a message.

## Return to the Inventory after a Removal

On the report screen after a Removal, Escape now reads the Inventory again and
returns to the Inventory view. `q` exits. In earlier releases, both keys closed
Lampwright.

## Managed Update keeps the agents of a Skill

In earlier releases, a Managed Update of a Vercel-managed Skill could add the
Skill to agent harnesses that did not have it. The `update` command of the
`skills` CLI has no option that selects agents, and it can link a new version
into each agent directory that it uses as a default target.

Lampwright now removes each link that the Owner command creates at a path that
did not exist before the Update, so the Skill has the same agents as before.
Lampwright removes links only. If the Owner command copies the Skill into an
agent directory, that copy stays, and the Update report states that the agents
of the Skill changed.

This correction applies to an Update that Lampwright runs. If you run
`npx skills update` directly, that command can still add links.

## Safety boundaries

Lampwright keeps these existing safety rules:

- Read-only Inventory scans, terminal browsing, plans, and dry runs create no
  persistent state. The saved theme is the one exception, and only a confirmed
  theme in the picker writes it.
- A scan uses no network access.
- Git-protected content and System Skills stay immutable.
- Lampwright does not replace a failed managed operation with a filesystem
  change.
- Lampwright has no telemetry and does not transmit Inventory, local paths,
  metadata, or search queries.

## Known limits

The hint row shows fewer keys on a narrow terminal. Each key is in the key
reference.

A custom theme can extend a built-in theme only.

The key reference needs a terminal of 22 rows or more to show its complete
panel. On a shorter terminal it drops spacing and then fills the screen.

The Update review does not yet warn that an Owner command can copy a Skill
into another agent directory.

After the GitHub `v0.4.0` release is available, run this version with:

```console
npx lampwright@0.4.0
```
