# Lampwright 0.5.1 release notes

Lampwright makes shortcuts and agent search easier to use in small terminals.
If a review is too small to read, Lampwright now waits for you to enlarge the
terminal and confirm the visible plan.

## Browse shortcuts in Help

Press `?` in Inventory, Disabled, or Trash. Choose a section on the left to
see its keys and actions on the right. Focus a shortcut to read its explanation
and mouse gesture in the bottom pane. In narrow windows the action wraps below
its key. Escape returns to the same browse position and checked rows.

## Search in Add agents

Focus an eligible Skill in Inventory and press `+`. Add agents now uses the
main search view. Type an agent name or alias to filter the results. In a wide
terminal, focusing an agent shows its destination beside the list. In a narrow
terminal, the results use the full width. Space checks an agent, and the
selection persists across searches. Enter reviews the checked agents or, if
none are checked, the focused agent.

## Confirmation in small terminals

If a removal, Disable, Enable, Update, Add agents, or Trash review cannot show
a body row, Lampwright displays a resize prompt. It keeps the plan and
discards confirmation input received while the review is hidden. Enlarge the
terminal to confirm the plan, or press Escape to go back. A picker that cannot
display its choices also ignores input that would change a selection or save
a theme.

## Inventory links

Two junctions or symbolic links to the same Skill now keep separate
Installations even when their file IDs are too large for JavaScript numbers
to distinguish. Inventory lists both paths under one Logical Skill, so you can
select either Installation by its own path.

## Terminal UI hosts

Custom hosts can continue to construct their existing screen states.
`TuiHelpState` adds optional fields for pane focus, the selected section and
key, pane sizes, and scroll positions. `TuiAddAgentPickerModel` adds an
optional `scroll` field for the first visible result. For custom search
renderers, use the `resultStartRow` and pane widths from `searchLayout` to
place results and handle clicks. A zero `rightWidth` means that the list
occupies the full width. For a custom pane layout, `layout` accepts the
number of header rows as an optional second argument. Send viewport changes
to the controller so it can check whether a review is visible before
accepting confirmation.

## Package verification

After npm accepts a publication, the release workflow waits for both the
exact version and its tarball to appear in the public registry. It then
installs the package and checks `--version` and `--help` on macOS, Linux,
and Windows.

After the GitHub `v0.5.1` release and npm publication, run this version with
the following command.

```console
npx lampwright@0.5.1
```

See the [terminal UI guide](../tui.md) and the [release checklist](../release.md).
