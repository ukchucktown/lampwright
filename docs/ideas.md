# Product ideas

This index captures product directions that are worth preserving but are not
accepted Lampwright behavior. An idea becomes implementation work only after it
is promoted to a GitHub issue and reconciled with the specification, domain
language, and relevant architectural decisions.

| Idea                                                          | Status | Summary                                                                                                                |
| ------------------------------------------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------- |
| [Track Skill usage and cost](./ideas/skill-usage-and-cost.md) | Seed   | Combine direct token-footprint analysis, harness-native usage evidence, and log-based fallback across agent harnesses. |

## Statuses

- **Seed**: Captured for later shaping; behavior and scope are unapproved.
- **Researching**: Feasibility or product questions are being investigated.
- **Proposed**: Shaped well enough to promote to a bounded GitHub issue.
- **Accepted**: Approved through an issue and incorporated into the appropriate
  source-of-truth documents.
- **Parked**: Intentionally deferred without rejecting the underlying problem.
- **Rejected**: Considered and declined, with the reason preserved in the idea
  document.
